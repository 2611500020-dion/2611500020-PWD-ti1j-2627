# pertemuan-01
Bukti Belajar P1 <br>
Fungsi: dokumentasi capaian pembelajaran P1 <br>
1. Konsep Dasar Pemrograman Web <br>
pemrograman web adalah proses pembuat dan pengembang situs web 
2. Arsitektur Klien-Peladen <br>
arsitektur adalah struktur aplikasi atau jaringan komputer yang membagi tugas antara klien 
3. HTTP Request dan Response <br>
adalah inti dari mekanisme komunikasi antara klien dan server 
4. HTML, CSS, JavaScript, PHP, MySQL <br>
html adalah bahasa markup website 
css adalah merubah menampilan website agar lebih menarik
javascript adalah bahasa perograman web lebih interaktif
php adalah mengembangkan situs web sesi server 
mysql adalah menyimpan, menggelolah data 
5. Hubungan Antarteknologi <br>
anatarteknologi adalah aplikasi web berbasis databes yang utuh
